Teaching notes

Fixed 9-case structure for a 5-minute warm-up: 4 Spot-the-Difference cases (one each for P1, N1, P3, N400), 2 Keep-Averaging cases, 2 artefact-ID cases drawn at random each playthrough from a bank of 4 (genuine component, eye-blink, muscle artefact, pure noise/no signal), and 1 epoching-alignment case. Artefact contexts are now generic (visual task / oddball task / sentence task / quiet rest) rather than naming the artefact source (e.g. jaw clench, blink), so students must judge from waveform shape and timing rather than the sentence giving it away. Spot-the-Difference is single-step (identify the differing component; the psychological interpretation is given directly in the feedback) to keep pace brisk for students new to ERPs. Keep-Averaging starts from a single raw trial that is genuinely unreadable (noise RMS \u2248 signal amplitude) and uses a slider up to 50 trials; noise falls off roughly with 1/\u221an, so the component becomes clearly visible well before 50 — fewer trials used before locking in an answer earns more points. The epoching case gives each of two trials its own independent slider for where the analysis window starts; only when both are dragged to align with that trial's own target onset (not a shared fixed time) does the live grand average resolve into a single clean peak, and the student then commits to a one-click judgement of whether the epochs are correctly aligned, scored like any other case — directly illustrating why epochs are defined relative to the event of interest, not the clock. Electrode/topography content has been removed entirely; the task rests on paradigm logic and waveform shape only.
