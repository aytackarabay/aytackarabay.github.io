Data format and figure guidance

JAMOVI: export your data as CSV. Select a numeric outcome and categorical factors. Numeric group codes such as 1, 2 and 3 can be used as factor levels.

Repeated measures: use long format, with one row per participant per condition. Assign the participant ID and explicitly mark the repeated factor as Within subjects to connect matching observations. Reshape wide repeated measures data before import. Both factors may be Within subjects. In the interaction view, choose which factor participant lines connect across; the other factor is held constant. Main effect views automatically connect the factor displayed on the X axis.

Main effects: a main effect view shows one factor averaged across the other selected factor. These observed marginal means describe the uploaded sample; they are not fitted or model adjusted means.

Marginal means: in a repeated design, trial rows are first averaged within each participant and condition, then available conditions are averaged within each participant for a main effect. Participants contribute equally within each displayed group. In a between subjects design without IDs, each row contributes equally. Unequal group sizes give sample weighted marginal means across between subjects groups.

Interaction plots: each combination of factor levels is shown separately. Nothing is collapsed across either factor. Lines between means help you compare the patterns across conditions.

Observation units: without an ID, each valid row is an observation. With an ID, each displayed point is a participant average. Missing conditions are not imputed. Data notes identify incomplete repeated observations.

Error bars: choose mean ± SD, mean ± SE, or an approximate 95% confidence interval given by mean ± 1.96 × SE. SE = SD / √n, where n is the number of observation units in the displayed group. The original Student t interval remains available and uses its critical value instead of 1.96. All measures require at least two observation units. In repeated designs, calculations use participant averages within the displayed condition. These are not intervals for paired differences.

Distributions: boxes show quartiles, a median and whiskers within 1.5 times the interquartile range. Violin and raincloud layers use kernel density estimates with equal maximum width, trimmed to the observed range. A density is omitted for constant groups or groups with fewer than two observations.

Exports: SVG preserves editable vector shapes and text. The PDF quality SVG uses the same vector geometry and can be opened in illustration or presentation software before PDF export. PNG exports include a standard size, the chosen high resolution size, a transparent background option and clipboard copying where the browser permits it. Manual brackets and custom axes are included. Saved HTML can retain the complete project without a network connection.

Figure Studio is a local visualisation tool for psychology students. Uploaded files are processed on your device. No inferential tests, assumption checks or interpretations are generated. Any comparison annotations are supplied manually by the user.
